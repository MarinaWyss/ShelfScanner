ShelfScanner Evaluation

Two kinds of failure, two kinds of test. The code can break, which deterministic tests catch. The model can answer wrongly while the code runs perfectly, which only an evaluation against labelled photos catches. Both run without anyone remembering, and the set grows from real use.
